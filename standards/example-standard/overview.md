# Example standard — naming

> Example entry. Replace with your team's real standards, each with its reason.

- **Booleans read as questions:** `isActive`, `hasInvoices`, `canEdit`. Reason: a bare `active`
  was read as a status string twice in review.
- **Services are named for what they do, not the model:** `InvoiceIssuer`, not `InvoiceHelper`.
- **One meaning per word.** If "account" means the login, the billing entity is "customer".
  Write the glossary here when the team agrees it.
